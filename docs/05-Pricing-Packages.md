# 05 — Pricing Packages

All prices in **PKR**. Optional **USD** for international/export.

---

## Pricing Model

| Component | Type | Description |
|-----------|------|-------------|
| **Platform fee** | Monthly | M00 Core (included in all packages) |
| **Module license** | Monthly per module | Per facility, unlimited users within tier cap |
| **Implementation** | One-time | Setup, config, training, data migration |
| **Infrastructure** | One-time or lease | Hardware per tier (optional — customer can self-provide) |
| **Support** | Annual | 15–20% of license fee |
| **Custom integration** | One-time | Lab analyzer, PACS, PITB |
