# PKG-A — Heart Clinic Starter

**First product to sell and install.** Prove the platform at smallest scale.

## Included Modules
- M00 Core Platform
- M01 Patient Registration
- M02 OPD (Cardiology template)
- M05 Appointments
- M08 Cardiology General

## Target Customer Profile
| Field | Value |
|-------|-------|
| Facility type | Heart clinic, cardiologist OPD |
| Doctors | 1–3 |
| Staff total | 3–8 |
| Patients/day | 20–80 |
| Rooms | 1–3 |
| Beds | 0 (OPD only) |
| Location | Urban — Rawalpindi, Islamabad, Lahore, Faisalabad |

## Installation Checklist
- [ ] Site survey (1 room min for server/PC)
- [ ] Internet check (or confirm offline mode)
- [ ] Install M00–M08 on server/PC
- [ ] Create 3 user accounts (doctor, nurse, reception)
- [ ] Load cardiology OPD template
- [ ] Print test MR card
- [ ] Train staff (2 days)
- [ ] Go-live with parallel paper (1 week)
- [ ] Paperless cutover

## Timeline: 2 Weeks

| Day | Activity |
|-----|----------|
